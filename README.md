# 도서신청 웹앱

교직원이 교보문고에서 책을 검색해 신청하고, 담당자는 시트 한 장으로 주문서를 받는 Google Apps Script 웹앱입니다.
신청 화면에서 그 책이 우리 학교 도서관(read365)에 이미 있는지도 함께 보여 줍니다.

만든 이: [구두방장선생](https://blog.naver.com/qkfkekdl)

## 주요 기능
- 교보문고 검색 → 도서명·저자·출판사·정가·할인가·ISBN 자동 입력 (교보 링크 붙여넣기도 가능)
- 학교도서관 소장 여부와 권별 대출 상태 표시 (독서교육종합지원시스템 read365)
- 교보에서 정보를 못 읽을 때 직접 입력 신청
- 내 신청내역 조회·취소, 관리자 [현황] 탭, 도서별 합계 주문서 시트 자동 생성
- 설정 점검 메뉴, 새 버전 알림

## 설치
배포용 시트 사본을 만들어 쓰는 것을 권장합니다. 자세한 순서는 블로그의 배포 매뉴얼을 참고하세요.

직접 설치하려면:
1. 새 구글 스프레드시트 > 확장 프로그램 > Apps Script
2. `Code.gs`, `index.html`(HTML 파일 추가) 내용을 붙여넣기
3. ⚙️ 프로젝트 설정 > "appsscript.json 매니페스트 파일 표시" 체크 후 `appsscript.json` 내용을 덮어쓰기
4. 시트를 새로고침하고 메뉴 `📚 도서신청 > ① 처음 세팅` → `② 학교도서관 연결하기` → `③ 설정 점검`
5. 배포 > 새 배포 > 웹 앱 (실행: 나)

## 업데이트
`Code.gs`, `index.html`을 새 버전으로 덮어쓴 뒤 **배포 > 배포 관리 > ✏️ > 새 버전**으로 배포하세요.
[새 배포]를 누르면 웹앱 주소가 바뀝니다. 바뀐 내용은 [CHANGELOG.md](CHANGELOG.md)에 있습니다.

### v1.1.1 이상 적용 시 (v1.1.0에서 업데이트)

1. `Code.gs`, `index.html`, **`appsscript.json`도 함께** 덮어씁니다.
2. 시트를 새로고침하고 `📚 도서신청 > ① 처음 세팅`을 한 번 실행합니다. 기존 신청내역과 설정은 유지되며, 웹앱에서 사용할 시트 ID가 저장됩니다.
3. 권한 요청이 나오면 다시 승인합니다. 웹앱이 저장된 ID로 시트를 열도록 스프레드시트 권한 범위가 변경되었습니다.
4. `③ 설정 점검`을 실행한 뒤 기존 배포에서 **새 버전**을 선택합니다.
5. 실제 배포 주소에서 신청·조회·취소·관리자 주문서 생성을 확인합니다.

직접 입력 도서의 예전 ID가 같더라도 전체 제목·저자·출판사로 구분합니다. ISBN이 있으면 ISBN을 기준으로 묶습니다. 이전에 충돌 때문에 신청하지 못했거나 기록에서 빠진 책은 다시 신청해야 합니다.

같은 도서라도 기록된 가격이 다르면 주문서 단가는 `신청별 상이`로 표시하고, 총액은 각 신청의 가격 × 수량을 합산합니다. 주문 시점의 실시간 가격은 별도로 확인하세요.

v1.1.2는 주문서 생성 후 열 너비와 행 높이를 자동으로 맞춥니다. 긴 제목·신청자 목록은 적당한 열 너비에서 줄바꿈합니다. v1.1.1에서 업데이트할 때는 `Code.gs`를 교체한 뒤 기존 배포에서 새 버전을 적용하면 됩니다.

## 로컬 회귀 검사

Node.js가 있는 환경에서 `node tests/regression.cjs`를 실행합니다. Apps Script 서비스는 모의 구현을 사용하므로 실제 배포·권한·외부 사이트 연결 검사를 대신하지 않습니다.

## 파일
| 파일 | 내용 |
| --- | --- |
| `Code.gs` | 서버 코드 (Apps Script) |
| `index.html` | 웹앱 화면 |
| `appsscript.json` | 시간대·권한 설정 |
| `version.json` | 최신 버전 정보 (설치된 웹앱이 새 버전 알림에 사용) |
| `CHANGELOG.md` | 버전별 변경 기록 |

## 알려진 제한
- 교보문고와 read365 화면을 읽어오는 방식이라, 두 사이트 구조가 바뀌면 업데이트가 필요합니다.
- 로그인 없이 이름으로 신청자를 구분합니다.
