계정 분리 접속 기능을 지원하지 않습니다. 최신 Chrome 또는 Edge를 사용하거나, 시크릿·개인정보 보호 창에서 원래 주소를 여세요. 공개 배포된 신청 화면은 Google 로그인이 필요하지 않습니다.

원래 주소 열기

화면이 안 열리거나 공유 주소가 필요한가요?

최신 Chrome·Edge에서 다시 열어 보세요. Google 오류 화면이 계속 나오면 시크릿 창에서 원래 주소를 여세요. 담당자는 배포 설정의 실행 계정이 ‘나’, 접근 범위가 ‘모든 사용자’인지 확인하세요.

신청자 이름은 화면을 새로 열 때마다 입력해야 합니다. 이름으로 조회하므로 이전과 같은 이름을 사용해 주세요.

다른 학교 주소를 입력하기 전, 담당자가 보낸 링크인지 확인하세요.
